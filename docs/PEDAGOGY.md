# Pedagogy and progression

## The learning problem this system addresses

Understanding a correction is easier than retrieving the corrected structure later. This template
therefore optimizes for:

- active recall;
- independent production;
- immediate, narrow feedback;
- transfer to a different context;
- spaced repetition;
- rewriting without looking at the correction;
- a small number of priorities at a time.

## Practice-first diagnostic loop

The system should not begin with a generic curriculum. A complete mock exam creates an authentic
sample of what the learner can and cannot yet do under task constraints. Correction then turns that
evidence into a small, individualized training cycle:

```text
complete mock exam
→ holistic correction of all three tasks
→ up to five shared priorities
→ daily retrieval from real errors
→ spaced review
→ rewrite without consultation
→ next complete mock exam
```

Short exercises repair the errors; they do not replace full writing. The next simulation is the
transfer test. A pattern is improving only when it survives a new task and context without direct
support.

## Cycle after a complete production

1. Write without assistance.
2. Receive a holistic correction.
3. Select no more than five priorities.
4. Practise those priorities through free production.
5. Reuse them in different contexts.
6. Rewrite a passage without consulting the correction.
7. Later rewrite the complete task.
8. Use the structures in a new complete production.

For a complete épreuve blanche, archive the task materials and all three untouched originals before
correction. The priority list should synthesize across the three tasks rather than creating a large,
separate backlog for every local edit.

## Daily cycle

The daily routine has two stages:

1. **Recent-error challenges.** All eligible priority errors remain here for at least the configured
   number of separate study days. A calendar date counts once, no matter how many retries occur.
2. **Spaced review.** All due structures are retrieved. If none is due, the nearest future item is
   selected so the routine does not become empty.

One item is presented at a time. A failed item remains the current item while the learner completes
one or more transfer attempts. Remediation does not create a new queue item and does not lower the
countdown.

After the minimum intensive-study days, the item graduates only when the latest use is correct and
independent. The default spaced delays are 3, 7, 14, and 30 days. At the last step, successful uses
continue at the maximum interval. A later failure reactivates the intensive challenge.

## Retrieval before explanation

The coach describes an intention in the base language and asks for a complete answer in French.
Before the attempt, it does not expose:

- the target expression;
- expected vocabulary;
- a French model;
- a sentence beginning;
- a partial translation;
- a word bank;
- a fill-in-the-blank sentence.

After a failure, the coach may show the corrected version of the learner's own sentence. It then
asks for a new application in a different setting. Reading the correction is not counted as a
correct use.

## Status model

### `new`

The pattern has been observed once.

### `recurring`

The pattern has appeared at least twice or returned after correction.

### `reviewing`

The pattern is being actively trained and still produces failures.

### `consolidating`

The learner has reused it correctly in more than one context but has not met mastery criteria.

### `mastered`

By default, mastery requires all of the following:

- at least five correct independent uses;
- at least three distinct contexts;
- at least one correct use in a complete production;
- no more than one recent failure.

An explanation, a copied answer, or temporary absence of the error is not mastery. A new failure may
reactivate a mastered item.

## Error frequency and action

| Evidence | Default interpretation | Action |
|---|---|---|
| First observation | New | Explain briefly and request transfer |
| Second observation | Recurring | Add focused practice |
| Third observation | Persistent priority | Consider an active structure |
| Four or more observations | Critical recurrence | Practise before the next full text |
| Three correct later uses | Consolidating | Continue monitoring |
| Five correct uses in three contexts | Mastery candidate | Verify in a complete production |

Communicative severity can raise priority earlier. A single task-fulfilment failure may matter more
than several low-impact accent mistakes.

## Vocabulary development

Vocabulary learning follows the same retrieval principles:

1. communicate the intended nuance in the base language;
2. let the learner choose the French wording;
3. accept a natural alternative even if it differs from the internal target;
4. after the attempt, distinguish correction from optional improvement;
5. if a new expression becomes a learning objective, require transfer and schedule it.

Avoid large synonym lists. Prefer one useful collocation, adjective, connector, or register choice
that can be used immediately.

## Cognitive limits

Default limits are:

- five correction priorities;
- one new structure in a session;
- twenty active structures;
- one item displayed at a time in the daily routine;
- all due reviews may be included, but they are never displayed at once.

The goal is to keep the learner writing more than reading explanations.

## Useful progress signals

Track:

- recurring errors by category;
- correct independent uses after correction;
- distinct contexts of successful reuse;
- complete-production transfer;
- task fulfilment and register;
- qualitative movement in task-level CEFR ranges;
- active, consolidating, and mastered structures.

Do not optimize for the number of notes, cards, or advanced words collected.
